## ✅ Tarefas Mais Comuns

### 1. Validar um Produto (2 minutos)

**Passo a passo:**
1. Dashboard → Toque em **"Validar Produtos"**
2. Veja a lista de produtos **Pendentes** (filtro ativo por padrão)
3. Toque em um produto para abrir os **detalhes**
4. Revise:
   - ✓ Imagem do produto
   - ✓ Nome, marca, categoria
   - ✓ Preço e código de barras
   - ✓ Estabelecimento que cadastrou
5. Decida:
   - **✓ Aprovar** (botão verde) → Produto vai para o catálogo
   - **✕ Rejeitar** (botão vermelho) → Produto é removido

**Resultado:** Status atualizado instantaneamente!

---

### 2. Aprovar um Mercado Novo (3 minutos)

**Passo a passo:**
1. Bottom Nav → Toque em **"Mercados"**
2. Filtre por **"Pendentes"** (alerta amarelo mostra quantidade)
3. Revise as informações do estabelecimento:
   - Nome e endereço
   - Telefone e horário
   - E-mail de contato
4. Decida:
   - **✓ Aprovar** (verde) → Mercado pode cadastrar produtos
   - **✕ Rejeitar** (vermelho) → Mercado não é aceito
5. *Opcional:* Se já aprovado, toque em **"Verificar"** para dar selo de verificado ✅

**Fluxo:**
```
Pendente → Aprovar → Aprovado → Verificar → Verificado ✓
```

---

### 3. Gerenciar Usuário Problemático (1 minuto)

**Passo a passo:**
1. Bottom Nav → Toque em **"Usuários"**
2. Use a **busca** ou **filtros**:
   - Todos | Ativos | Bloqueados
3. Encontre o usuário
4. Ações disponíveis:
   - 🔵 **Editar** → Alterar dados
   - 🔴 **Bloquear** → Suspender acesso (reversível)
   - 🗑️ **Excluir** → Remover permanentemente

**Dica:** Usuários bloqueados aparecem com fundo vermelho claro!

---

### 4. Ver Relatórios de Crescimento (2 minutos)

**Passo a passo:**
1. Bottom Nav → Toque em **"Relatórios"**
2. Selecione o período:
   - **7 dias** (dados diários)
   - **30 dias** (dados semanais)
   - **90 dias** (dados mensais)
   - **1 ano** (dados trimestrais)
3. Analise:
   - 📊 **Gráfico de crescimento** de usuários
   - 🏆 **Top 5 produtos** mais buscados
   - 🏪 **Top 5 mercados** mais ativos
   - 📈 **Resumo do período** (interações, tempo médio, retenção)

**Dica:** Toque no botão 📥 para exportar (futuro)

## ⚙️ Configurações Importantes

### Como Acessar:
Bottom Nav → **"Config"** OU Dashboard → Ícone ⚙️ no header

### Configurações Essenciais:

#### 🔒 Segurança
- **Autenticação de Dois Fatores** → Ative para proteger sua conta
- **Logs de Auditoria** → Veja histórico de ações administrativas

#### 🔧 Sistema
- **Modo Manutenção** ⚠️ → Desativa acesso temporariamente (use com cuidado!)
- **Aprovação Automática** → Auto-aprovar produtos de mercados verificados
- **Backup** → Criar cópia de segurança do banco de dados

#### 🔔 Notificações
- **Push** → Ative para receber alertas de atividades importantes
- **E-mails de Resumo** → Relatórios diários

## 🎯 Atalhos e Dicas

### Atalhos Visuais
- **Badge vermelho com número** → Itens pendentes (ex: 47 produtos para validar)
- **Dots coloridos** → Prioridade (🔴 alto, 🟡 médio, 🟢 baixo)
- **Bordas coloridas** → Status (🟡 pendente, 🔵 aprovado, 🟢 verificado, 🔴 rejeitado)

### Navegação Eficiente
- Use **busca** para encontrar rápido (usuários, mercados, produtos)
- Use **filtros** para ver apenas o que importa
- **Bottom Nav** sempre disponível → navegue sem voltar ao dashboard

### Boas Práticas
- ✅ Valide produtos regularmente (alerta mostra quantidade pendente)
- ✅ Responda mercados pendentes em até 24h
- ✅ Revise relatórios semanalmente
- ✅ Mantenha backup atualizado
- ❌ NÃO ative Modo Manutenção sem necessidade

## 🆘 Problemas Comuns

### "Não consigo ver o botão de trocar modo"
→ Verifique se você está logado. O botão só aparece após o login.

### "Mercado pendente não aparece"
→ Use o filtro "Pendentes" na tela de Mercados.

### "Gráfico não atualiza"
→ Selecione outro período e volte. Dados são mockados.

### "Onde vejo quem fez uma ação?"
→ Vá em Config → Logs de Auditoria (futuro).
